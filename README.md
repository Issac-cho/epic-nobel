# LightCell (v1.1.0) 📊

LightCell은 C++ 및 Qt를 기반으로 개발된 가볍고 빠르며 엑셀과 완벽히 호환되는 훌륭한 스프레드시트 애플리케이션입니다.
다양한 디자인과 필수 단축키, 그리고 크로스 시트 연산 등을 지원하여 사용자에게 쾌적한 데이터 입력 환경을 제공합니다.

## ✨ 📊 LightCell v1.1.0 핵심 기능 요약

**1. 엑셀 완벽 호환 단축키 및 커서 이동**
* **스마트 커서 점프 (`Ctrl + 방향키`)**: 데이터가 있는 연속된 셀의 끝부분이나 가장 가까운 빈 셀로 단숨에 점프합니다.
* **스마트 다중 선택 (`Ctrl + Shift + 방향키`)**: 커서가 점프하는 궤적을 따라 셀 영역을 한 번에 드래그하여 선택합니다.
* **행/열 키보드 다중 선택 (`Shift + 방향키`)**: 행이나 열 전체를 선택한 뒤, 방향키를 사용하여 여러 행이나 열을 빠르고 손쉽게 다중 선택할 수 있습니다.
* **안전한 데이터 삭제 (`Delete`)**: 엑셀처럼 `Backspace`가 아닌 `Delete` 키만을 이용해 선택된 셀들의 데이터를 안전하게 지웁니다.
* **실행 취소 및 재실행 (`Ctrl+Z`, `Ctrl+Y` / `Ctrl+Shift+Z`)**: 셀 편집 중이 아닐 때 자유롭게 작업 내역과 셀 크기 조절 내역까지 되돌리거나 복구할 수 있습니다.

**2. 강력한 수식 및 교차 시트 연산 (Cross-sheet Reference)**
* **기본 사칙연산 및 SUM**: `=A1+B1`, `=SUM(A1:B5, C1:C5)` 등 다중 인자를 포함한 수식을 완벽하게 파싱하여 계산합니다.
* **마우스 인터랙티브 수식 작성**: 셀에 `=`를 입력한 뒤, 화면에 있는 다른 셀들을 클릭하거나 마우스로 드래그하면 주소(예: `A1:B3`)가 수식에 자동으로 입력됩니다.
* **타 시트 연동 계산**: 수식 작성 중 다른 시트 탭을 눌러 넘어가서 셀을 클릭하면 `=Sheet2!B3`처럼 타 시트 참조 주소가 자동으로 붙습니다.

**3. 다중 시트(Tab) 및 행/열 관리**
* `Ctrl+T`로 새 시트를 빠르게 추가할 수 있습니다.
* `Ctrl+Tab` 및 `Ctrl+Shift+Tab`을 이용해 마우스 없이도 시트 탭 사이를 자유롭게 넘나들 수 있습니다.
* 시트 탭 우클릭을 통해 **시트 이름 변경**, **시트 복제**, **시트 삭제**를 손쉽게 할 수 있습니다.
* **다중 행/열 너비 일괄 조절**: 여러 행이나 열을 동시에 선택한 상태에서 하나만 너비나 높이를 조절하면, 선택된 모든 행과 열이 동일한 크기로 한 번에 조절됩니다.

**4. 픽셀 단위 컨트롤이 가능한 인쇄(Print) 엔진**
* `Ctrl+P`를 통해 인쇄 미리보기 화면을 띄울 수 있습니다.
* 표를 종이의 **가로/세로 정중앙**에 배치할 수 있으며, 격자선 옵션을 끄더라도 굵은 테두리가 명확하게 출력되도록 렌더링 개선이 적용되었습니다.
* 스핀 박스(SpinBox)를 이용해 **1픽셀 단위로 상하좌우 오프셋을 미세 조정**하여 정확한 위치에 인쇄할 수 있습니다.

**5. 풍부한 셀 서식(스타일) 및 정렬**
* 글꼴(폰트), 글자 크기, 굵게, 기울임, 밑줄, 취소선 등 다양한 서식을 지원합니다.
* 글자 색상 및 배경 색상을 변경할 수 있으며 **셀 병합(Merge Cells)**, 텍스트 방향 맞춤을 지원합니다.
* **회계 형식 (Accounting Format)**: 숫자의 천 단위마다 쉼표(,)를 찍고, `0`값은 `-`으로 깔끔하게 표시하는 전용 포맷을 지원합니다.
* **세로쓰기 (Vertical Text)**: 텍스트를 가로가 아닌 위에서 아래 방향으로 입력하고 정렬할 수 있습니다.
* **셀 테두리 (Borders)**: 엑셀처럼 회색 기본 격자선을 덮어씌우는 굵은 테두리를 명확하게 지정할 수 있습니다.

**6. 데이터 입출력 및 배포**
* 전용 포맷 저장 및 불러오기, 엑셀 파일 형식 내보내기 기능을 탑재하고 있습니다.
* 사용자가 설치하기 편하도록 **정식 윈도우 설치 프로그램(.exe)**을 제공하여 바탕화면 아이콘 자동 생성과 제어판 앱 삭제를 완벽히 지원합니다. (포터블 무설치 버전도 함께 제공됩니다.)

**7. 검색(Find) 및 필터(Filter)**
* 단축키(`Ctrl+Shift+L`)를 통해 특정 값만 보거나 헤더 오름차순/내림차순 정렬을 수행할 수 있습니다.
* 문서 전체에서 원하는 데이터를 찾는 기능(`Ctrl+F`)이 단축키로 탑재되어 있습니다.

## 📥 설치 및 실행 방법 (Windows)

사용자의 편의에 따라 두 가지 설치 방식을 지원합니다. 깃허브의 **Release 탭**에서 원하시는 버전을 다운로드하세요.

1. **정식 설치 버전 (추천)**: `LightCell_Setup_v1.1.0.exe`를 다운로드하여 실행하면 바탕화면 바로가기가 생성되며 윈도우 앱으로 정상 등록됩니다. 추후 패치 시에도 설치 파일만 실행하면 안전하게 자동 덮어쓰기가 진행됩니다.
2. **무설치 포터블 버전**: `LightCell_v1.1.0.zip`을 다운로드하고 압축을 풀면 별도의 설치 과정 없이 `LightCell.exe`를 곧바로 실행할 수 있습니다.

### 🛠 직접 빌드 및 패키징 (개발자용)

소스코드를 직접 빌드하고 배포용 설치 파일(`.exe` 및 `.zip`)을 생성하고 싶으시다면 동봉된 스크립트를 사용하세요.

1. 본 레포지토리를 클론합니다.
2. 시스템에 Qt 6.x와 CMake, 그리고 Inno Setup이 설치되어 있어야 합니다.
3. Windows 시작 메뉴에서 **'Qt x.x.x (MinGW) Command Prompt'** 를 검색하여 실행합니다.
4. 아래 명령을 실행하여 포터블 압축 파일(`.zip`)을 생성합니다:
   ```powershell
   powershell.exe -ExecutionPolicy Bypass -File .\build_installer.ps1 -Version "v1.1.0"
   ```
5. 생성된 `setup.iss` 파일을 더블클릭하거나 Inno Setup 컴파일러(ISCC)를 통해 컴파일하면 `Output/LightCell_Setup_v1.1.0.exe`가 최종 생성됩니다.

## ⌨️ 단축키 요약 (Shortcuts)

### 📍 이동 및 선택
* **`Ctrl + 방향키`**: 상하좌우 데이터가 있는 셀의 끝이나 가장 가까운 빈 셀로 커서가 단숨에 이동
* **`Ctrl + Shift + 방향키`**: 이동 궤적을 따라 셀 영역 다중 선택
* **`Shift + 방향키` (헤더 클릭 시)**: 여러 행이나 열을 다중 확장 선택
* **`Tab` / `Enter`**: 입력하며 우측/아래로 이동

### ✏️ 편집 및 탐색
* **`Delete`**: 선택된 셀들의 데이터를 안전하게 삭제
* **`Ctrl + Z`**: 실행 취소 (크기 조절 포함)
* **`Ctrl + Y` / `Ctrl + Shift + Z`**: 재실행
* **`Ctrl + F`**: 텍스트 찾기
* **`Ctrl + Shift + L`**: 데이터 필터

### 📑 시트(Tab) 관리
* **`Ctrl + T`**: 새 시트 생성
* **`Ctrl + Tab` / `Ctrl + Shift + Tab`**: 다음/이전 시트로 이동

### 💾 파일 및 출력
* **`Ctrl + N`**: 새 문서 만들기
* **`Ctrl + O`**: 열기
* **`Ctrl + S`**: 저장 / **`Ctrl + Shift + S`**: 다른 이름으로 저장
* **`Ctrl + P`**: 인쇄 미리보기 및 설정
